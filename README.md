# Anderssons Rörservice

Färdig statisk webbplats med 18 HTML-sidor, CSS, JavaScript och lokala bilder.
Ingen installation eller byggprocess behövs.

## Lägg upp på GitHub

1. Packa upp ZIP-filen.
2. Lägg innehållet i mappen `anderssons-rorservice-github` direkt i ditt repos rot, så att `index.html` ligger överst.
3. Spara filerna i GitHub.
4. Om du använder GitHub Pages: välj publicering från din huvudgren och repots rotmapp.

Länkar och bilder fungerar även på en GitHub Pages-adress med reponamn i sökvägen.

## Senaste ändringen

- Vit bakgrund med mörkblå profilfärger från användarens referens: #061827, #12334a, #234e76, #3e86b0 och #f2f5f6.
- Stor bildhero med tydliga kontaktknappar, serviceinformation och ett Google-omdöme.
- Personalbilder med samma överkant och bildhöjd, bredvid varandra på mobil och dator.
- Företagets ursprungliga logotyp i svartvitt. Inget färgfilter används på sidan.

## Ändra webbplatsen

- `index.html`: startsidan.
- Övriga `.html`-filer: undersidor.
- `style.css`: färger, utseende och mobilanpassning.
- `script.js`: menyer och tangentbordsnavigering.
- `assets/`: bilder, logotyp och typsnitt.

Google-omdömena är ett statiskt urval av individuella femstjärniga recensioner från företagets befintliga webbplats. De uppdateras inte automatiskt och visas inte som ett samlat snittbetyg.
Interiörbilder används som inspiration, inte som utförda referensprojekt.
Typsnittets licens finns i `assets/FONT-LICENSE.txt`.

## Förhandsvisa lokalt

Öppna `index.html` i en webbläsare, eller använd en lokal webbserver.
